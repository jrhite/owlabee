New Chapter 11 and Chapter 7 Filings from PACER RSS Feeds

Bankruptcy courts publish their docket activity in public RSS feeds, and most put the chapter in front of each entry. This guide shows how to turn those feeds into a running list of new Chapter 11 and Chapter 7 petitions in Delaware, the Southern District of New York and the Texas bankruptcy courts.

How bankruptcy entries are read

  • Most bankruptcy courts put a prefix before the entry text, for example Type: bk Office: 1 Chapter: 7 Trustee: …. The Actor reads bankruptcyChapter, trustee and office from it, or the chapter from the entry text.
  • bankruptcyChapters keeps entries under the chapters you list (7, 9, 11, 12, 13 or 15). Entries without a chapter are dropped when it is set.
  • newCasesOnly keeps document number 1 of each case, which in a bankruptcy case is the petition. caseTypes: ["bankruptcy"] leaves out adversary proceedings, which have their own case type.
  • Bankruptcy case numbers often have no type code (26-11511), and some courts append judge initials or the chapter. The Actor keeps the number as published and adds a normalized caseNumberShort.

Limits worth knowing

  • Each feed covers only the trailing 24 hours. Schedule hourly or at least daily.
  • The feed carries the case title and the short docket text only; open docketUrl on PACER for the filing itself.
  • This page describes public docket data and how to filter it. It is not legal or financial advice.

Use cases

Hourly Chapter 11 alerts

Schedule the input below hourly with a webhookUrl. Only petitions not seen on earlier runs are sent.

Chapter 7 only, one court

Set courts: ["deb"] and bankruptcyChapters: ["7"] for the README's ready-made Delaware Chapter 7 feed.

Every live court in a state

Use a state code such as courts: ["TX"], which expands to every court in that state with a live feed at the last sweep, district courts included. caseTypes: ["bankruptcy"] keeps only bankruptcy cases.

With curl

The sync endpoint starts a run, waits up to 300 seconds and returns the dataset items. New Chapter 11 and Chapter 7 petitions in four bankruptcy courts, new since the last run:

export APIFY_TOKEN=<your Apify API token>

curl -sS -X POST \

    "deb",
    "nysb",
    "txsb",
    "txnb"

  "caseTypes": [
    "bankruptcy"

FAQ

Where does the chapter come from?

From the "Chapter:" prefix most bankruptcy courts publish before the entry text, or from the entry text itself.

Why are adversary proceedings left out?

They have their own case type, adversary. Remove caseTypes, or add adversary, to include them.

Does the first run send everything?

The first run with onlyNewSinceLastRun is a baseline. Later runs emit only entries not seen before.

Can I watch for a specific debtor?

Yes. partyKeywords matches the case title, and caseNumbers follows one case.

Is this legal or financial advice?

No. It describes public docket data and how to filter it.
