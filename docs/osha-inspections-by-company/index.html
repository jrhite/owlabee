OSHA Inspections by Company: DOL Data API Lookup

OSHA inspection and citation data is published by the U.S. Department of Labor through its Data API. This Actor looks up inspections by company name or inspection number and returns one record per inspection with its violations and penalties, graded by how well the establishment name matched.

The source and its limits

The data comes from the DOL Data API v4 (apiprod.dol.gov), datasets OSHA/inspection and OSHA/violation. It includes federal OSHA and State Plan inspections as DOL publishes them.

The DOL API needs a key. Keys are free: sign in at dataportal.dol.gov, open your account's API keys page, and pass the key as dolApiKey. It is stored as an encrypted secret and only sent to apiprod.dol.gov. Without a key the Actor still runs its EPA source (see EPA ECHO enforcement) and writes one DOL_API_KEY_MISSING item for OSHA.

How name matching works

Agencies record establishment names, not company ids, so every record carries matchConfidence and matchBasis:

  • high: names equal after removing case, punctuation and suffixes such as Inc or LLC, or an exact osha: identifier lookup.
  • medium: your name is a whole-word prefix of the agency's name ("Tesla" and "TESLA MOTORS INC").
  • low: your words appear elsewhere in the name, or only as part of a word.

minMatchConfidence (default medium) drops weaker matches before they are written or charged, and the summary record lists every distinct matched name separately.

Limits worth knowing

  • Inspections come back newest first. A short or generic name scans more rows; add a state or ZIP.
  • Agency data lag the agencies' own systems, and statuses and penalties can change after an inspection is first published.
  • Each agency has a time budget per run (timeBudgetSecs, default 300 seconds), at roughly one to three seconds per company.

With curl

The sync endpoint starts a run, waits up to 300 seconds and returns the dataset items. OSHA inspections since 2021 for two companies in Texas (replace the key placeholder with your own free DOL key):

export APIFY_TOKEN=<your Apify API token>

  "https://api.apify.com/v2/acts/owlabee~osha-epa-enforcement-report/run-sync-get-dataset-items" \
  -H "Authorization: Bearer ${APIFY_TOKEN}" \
  -H "Content-Type: application/json" \

    "Acme Roofing",

  ],
  "state": "TX",
  "dateFrom": "2021-01-01",
  "sources": [
    "osha"
  ],
  "dolApiKey": "<your free DOL API key>",
  "minMatchConfidence": "medium"
}'

FAQ

Why does OSHA need a key when EPA does not?

The DOL Data API does not answer without one. The key is free from dataportal.dol.gov and only used for apiprod.dol.gov.

Why did I get records for a different company?

Agencies record establishment names. Check matchConfidence and matchBasis, raise minMatchConfidence to high, add a state or ZIP, or look up exact identifiers.

Are State Plan inspections included?

Yes, as DOL publishes them in the same datasets.

Is this a rating of the company?

No. Records describe what the agency published, nothing more.

Can I get EPA cases in the same run?

Yes. Add epa to sources. The per-company summary then counts records and penalties by agency.
