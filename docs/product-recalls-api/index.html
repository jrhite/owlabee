Product Recalls API: FDA, NHTSA and CPSC in One Feed

Three federal agencies publish US recalls, each with its own API and field names. This Actor reads all three and writes each recall as one record with the same fields: agency, recall id, date, product, hazard, classification, firm, remedy and a link to the official notice.

cpscCPSC consumer product recallswww.saferproducts.gov/RestWebServices/RecallDaily

Limits worth knowing

  • openFDA allows 240 requests per minute and 1,000 per day per IP without a key. A free openFDA key (fdaApiKey) raises those limits.
  • FDA lists a recall in its enforcement report after classifying it, which can be weeks after the firm's announcement. NHTSA and CPSC publish within days. Use a daysBack of 30 or more for FDA.
  • CPSC has no server-side keyword or firm search, so the whole date window is downloaded and filtered locally.
  • FDA enforcement reports have no remedy field, so remedy is null for FDA recalls.

Fields you get

FieldWhat it holds
agency, source, recallIdFDA recall number, NHTSA campaign number or CPSC recall number
date, title, product, productType, descriptionWhat was recalled and when
hazardFDA reason for recall, NHTSA consequence summary, or CPSC hazards

Use cases

Daily Class I alert

Schedule fda-drug and fda-food with fdaClassifications: ["Class I"] and onlyNewSinceLastRun. The first run is a baseline; later runs post only new recalls to your webhook.

Recalls on a fleet's vehicles

List vehicles as make, model, year in vehicles. Each lookup returns every NHTSA recall on that vehicle, whatever the date window.

One hazard across agencies

Search a keyword such as lithium across cpsc, nhtsa and fda-device over a year to see related recalls side by side.

How to run it

You need an Apify account and its API token (Console → Settings → API & Integrations). Each run is billed per result to your account; set a maximum total charge for the run to cap spend.

With curl

The sync endpoint starts a run, waits up to 300 seconds and returns the dataset items. Class I food and drug recalls from the last 14 days, new ones only, posted to a webhook:

export APIFY_TOKEN=<your Apify API token>

curl -sS -X POST \
  "https://api.apify.com/v2/acts/owlabee~product-recall-feed/run-sync-get-dataset-items" \
  -H "Authorization: Bearer ${APIFY_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
  "agencies": [
    "fda-drug",
    "fda-food"
  ],
  "daysBack": 14,
  "fdaClassifications": [
    "Class I"
  ],
  "onlyNewSinceLastRun": true,
  "webhookUrl": "https://example.com/hooks/recalls"
}'

FAQ

Do I need API keys?

No. All three agencies have public APIs. An openFDA key is optional and only raises openFDA's rate limits.

Why is a recall from the news missing?

FDA lists recalls in enforcement reports after classifying them, often weeks later. NHTSA and CPSC publish faster.

Why is severity null for CPSC?

CPSC publishes no recall class. FDA classes map to high, medium and low, and NHTSA recalls with a do-not-drive or park-outside advisory are high.

What happens if one agency API is down?

That feed yields one error item and the others continue.

Can I see the agency's original fields?

Yes. includeRaw attaches the agency record as a nested raw object.
