How this page is made

Generated on November 8, 2026 (2026-11-08T04:16:05Z) from 2 runs of our own Building Permits Scraper — Roofing & Construction Leads Actor, each with a small fixed input and a spending cap. Each record is cut down to permit type, status, dates, valuation, permit number and the street and city of the site. It is refreshed once a week. The records shown are a sample, not the full feed: the Actor returns every record in the window.

The same records as JSON: data/permits.json. To reproduce them, run the Actor with these inputs:

FAQ

How do I get every permit, or only roofing or solar permits?

Run Building Permits Scraper — Roofing & Construction Leads with your cities, a date window and permitTypes such as ["roof", "solar"], or a minEstimatedCost. Monitor mode (onlyNewSinceLastRun) on a daily schedule returns only permits not seen before.

Which cities are covered?

The Actor reads 120 official open-data datasets: 102 US cities, counties, states and trade-permit datasets, and 18 Canadian ones. The building permits API guide explains the fields; the Actor's README lists every jurisdiction.

What about cities on Accela or EnerGov portals?

A sister Actor reads those: Accela Citizen Access & EnerGov Permit Scraper (Any City), in the same schema.
