FAQ

How do I get every recall, not just this sample?

Run Product Recall Feed — FDA, NHTSA & CPSC Recalls API with the input shown above and a larger maxResultsPerSource, or turn on onlyNewSinceLastRun and schedule it daily to receive only new recalls, by webhook if you like.

Can I filter by keyword, firm or vehicle?

Yes. The Actor takes a keyword (for example "salmonella" or "lithium battery"), a firm name, FDA recall classes and "make, model, year" vehicle lookups. The product recalls API guide lists every field.

Is USDA FSIS (meat and poultry) included?

No. The Actor reads FDA, NHTSA, CPSC and the Canadian, UK and EU feeds listed above. FSIS publishes its own recall API; see the recall data sources comparison.
