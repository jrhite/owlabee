About the snapshots

Each page shows a sample of the newest records, cut down to a few fields, and links to the same records as JSON in /data/. Each source's attribution and licence line is on its page. Names of individuals are never shown: permits list the street, not the house number, and grant pages list the opportunity, not its contacts.

For the full feed, your own filters or a daily schedule, run the Actor behind each page on Apify Store; every page links to it.
