The source and its limits

Everything comes from public sources: DNS records over DNS-over-HTTPS (Cloudflare, with Google as fallback), registration data from RDAP (the successor to WHOIS), and each domain's own TLS and HTTP endpoints. No API keys, proxies or browser.

The dns section reads A, AAAA, MX, NS, TXT, CAA and SOA records and checks:

  • SPF: record present, syntax, lookup count and the all qualifier.
  • DMARC: policy, subdomain policy, pct, and aggregate and forensic reporting addresses.
  • DKIM: 18 common selectors probed, plus any you add.
  • MTA-STS record and policy mode, and BIMI.

How the email security score is computed

CheckPoints
SPF record present and valid (10 lookups or fewer, no unknown terms, single record)25
DMARC policy reject / quarantine / none35 / 20 / 5
At least one DKIM selector found25
MTA-STS record present10
BIMI record present5

Limits worth knowing

  • DKIM selectors cannot be listed from outside, only probed. A domain whose selector is not in the list shows no DKIM even if it is configured; add your provider's selector in dkimSelectors.
  • The SPF lookup count covers the top-level record only (includes are not followed), so it is a lower bound.
  • Subdomains are reduced to their registrable domain, and many registries redact WHOIS contact data.
  • All sections of a domain share a 20-second budget; a slow source marks its own section as an error without blocking the others.

You need an Apify account and its API token (Console → Settings → API & Integrations). Each run is billed per result to your account; set a maximum total charge for the run to cap spend.

With curl

The sync endpoint starts a run, waits up to 300 seconds and returns the dataset items. SPF, DMARC and DKIM for ten domains, DNS section only:

export APIFY_TOKEN=<your Apify API token>

curl -sS -X POST \
  "https://api.apify.com/v2/acts/owlabee~domain-intelligence/run-sync-get-dataset-items" \
  -H "Authorization: Bearer ${APIFY_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
  "domains": [
    "example.com",

    "cloudflare.com",
    "mozilla.org",
    "wikipedia.org",

    "dns"

  "dkimSelectors": [],
  "maxConcurrency": 5

FAQ

Why does a domain show no DKIM when I know it has it?

DKIM selectors are not discoverable. The Actor probes 18 common ones; add yours in dkimSelectors (for example fm1 for Fastmail or krs for Klaviyo).

Does it send email or change anything?

No. It only reads public DNS, RDAP, TLS and HTTP responses.

How many domains can I check?

The list has no fixed cap. Up to 20 domains run in parallel (maxConcurrency), and the run stops cleanly at its maximum total charge.

Why is a WHOIS field empty?

Most registries redact personal data, and some country domains offer no RDAP. The Actor reports exactly what the registry returns.

What if a site has no web server?

tls.status and http.status become unavailable; the DNS and WHOIS sections are still filled.
