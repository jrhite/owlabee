EPA ECHO Enforcement Cases by Company or Facility

EPA's Enforcement and Compliance History Online (ECHO) records federal and state environmental enforcement cases. Its case search cannot filter by company name, so this Actor finds a company's facilities first and then reads their cases, returning one normalized record per case.

The source and its limits

EPA ECHO web services (echodata.epa.gov) publish enforcement cases with the case number and name, category, status, primary law (CAA, CWA, RCRA and others), filing and settlement dates, federal and state or local penalties, and the outcome. No key is needed.

Because ECHO's company-name filter for cases is not usable, the Actor runs a facility search for each company and then reads the case lists of the matched facilities. By default it checks only facilities that ECHO flags with formal enforcement actions or penalties; epaAllFacilities checks every matched facility, up to maxFacilitiesPerCompany. You can also look up a facility directly by its 12-digit FRS registry id with frs:<id>.

ECHO includes state-led and locally led cases that states report to EPA. State agencies' own systems are not queried.

Limits worth knowing

  • A very broad name can exceed ECHO's query limit and returns a QUERY_TOO_BROAD item; add a state or ZIP.
  • A case found through a matched facility can be filed under another party's name. Its matchConfidence is then low and matchNote says so.
  • Agency data lag EPA's internal systems, and statuses and penalties can change after a case is first published.

Use cases

Due diligence on a facility

Look up a plant by FRS id and read every case filed against it, with the law involved and the outcome.

Supplier screening without a key

Run sources: ["epa"] for a list of supplier names and states. EPA needs no key, so this works before you request a DOL key.

Scheduled watch

Turn on monitor to write only new or changed cases, fingerprinted by status, penalty and closing date, and post them to a webhook.

  -H "Content-Type: application/json" \
  -d '{

    "Tesla"

  "state": "CA",
  "sources": [
    "epa"
  ]
}'

FAQ

Does EPA ECHO need an API key?

No. ECHO web services are public. Only the OSHA source needs a key.

Why does it search facilities first?

ECHO's company-name filter for cases is not usable, so cases are found through the facilities that match the name.

Are state cases included?

Cases that states report to EPA are in ECHO and are returned (the lead agency is in the raw case data). State agencies' own databases are not queried.

How do I avoid records for similarly named companies?

Add a state or ZIP, raise minMatchConfidence, or look up facilities by FRS id.

What does the summary record contain?

Per company: record counts and penalty totals by agency, open records, counts by match confidence, the most recent action and every matched name.
