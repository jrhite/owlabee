Professional License Lookup: 7 States and the NPI Registry

State licensing boards publish their license records in different places and formats. This Actor queries ten official boards in seven states plus the federal NPI Registry, by license number or by name within one board, and returns one normalized record per license with a status and an expiration date. The board's disciplinary fields are available on request.

The first five sources are the default; the six opt-in boards answer only when you list them in sources or name their board in a query. Queries are one line each: TX:3365:Master Electrician, name:Jane Smith:FL, npi:1003000126, or pinned to a board with tdlr:, dbpr:, dora:, doh:, elicense:, bon:, tmb:, trec:, mylicense: or lara:. A query with a state goes only to that state's enabled boards. A license number without a state goes to every enabled source; a name without a state or board is answered only when exactly one source is enabled, because name lookups work within one board and are never a search across states.

Limits worth knowing

  • Texas publishes no status column, so its status is derived from the expiration date (statusDerived: true).
  • Open-data extracts can lag the board's live database: Colorado and Washington refresh daily, Texas less often.
  • Florida returns the first 50 matches of the portal's result page. Common names can match hundreds of licenses; narrow with a state, license type or city.
  • New Jersey and Michigan are read one lookup at a time.
  • Other states return an INVALID_QUERY item that names the supported ones. California's DCA and CSLB lookups are not included.
  • Each record notes that you should confirm with the issuing board before relying on it.

Use cases

Check a contractor's trade license

Look up an electrician or HVAC contractor by number in TDLR, or a Florida contractor in DBPR, and read the status and expiration date.

Bulk provider lookups

Send a list of NPIs or names to the NPI Registry and get taxonomy codes and the self-reported state license number for each.

Status-change watch

Turn on monitor to write only licenses that are new, changed (status or expiration) or removed since the last run.

With curl

The sync endpoint starts a run, waits up to 300 seconds and returns the dataset items. One NPI and one Texas name search in verify mode (the Actor's own quick-start input):

export APIFY_TOKEN=<your Apify API token>

curl -sS -X POST \
  "https://api.apify.com/v2/acts/owlabee~license-verification-api/run-sync-get-dataset-items" \
  -H "Authorization: Bearer ${APIFY_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
  "queries": [
    "npi:1003000126",
    "name:John Smith:TX"
  ],
  "lookups": [],
  "mode": "verify",
  "sources": [
    "TX_TDLR",
    "FL_DBPR",
    "CO_DORA",
    "WA_DOH",
    "NPI"
  ],
  "maxResultsPerQuery": 5,
  "maxResults": 20,
  "monitor": false
}'

FAQ

Which states are covered?

By default Texas (TDLR trades and occupations), Florida (DBPR professions), Colorado (all DORA professions) and Washington (health-care credentials), plus every US health-care provider through the NPI Registry. Opt-in: Texas nursing (BON), medicine (TMB) and real estate (TREC), Connecticut (all eLicense credentials), New Jersey (all Division of Consumer Affairs professions) and Michigan (all LARA license types).

Where is the disciplinary flag?

Off by default. Set includeDiscipline: true and boards that publish disciplinary fields (Colorado, Washington, Texas BON, Texas Medical Board, New Jersey and Michigan) return them as published. The Actor adds no severity or risk score.

What does verified mean?

The license was found, its status is ACTIVE and the expiration date is today or later. Statuses such as "Active - With Conditions" normalize to PROBATION and do not verify.

Is this the board's official verification?

No. It reads the boards' public records and links each one. Confirm with the issuing board before relying on a result.

Why do I get several records for one number?

License numbers repeat across license types in Texas and Colorado. Add the type, for example TX:3365:Master Electrician.

Does it need proxies or a key?

No. A free Socrata app token is optional and only raises rate limits on the Socrata open-data datasets.
