SAM.gov Contract Opportunities API Feed by Keyword

SAM.gov publishes federal contract opportunities (solicitations, presolicitations, sources sought and award notices) through its Get Opportunities API. With your own free SAM.gov key, this Actor searches it by keyword and filters, and flags notices that are new or changed since the last run.

The source and its limits

The SAM.gov Get Opportunities API is the official public API for federal contract notices. It requires a free personal API key, which any individual can request; no entity registration is needed:

  1. Create or sign in to an account at sam.gov.
  2. Open your profile, then Account Details.
  3. Under Public API Key, click Request, enter your password and copy the key.
  4. Pass it as samApiKey. It is stored as an encrypted secret input and never written to logs.

samFilters passes naics, setAside, state and ptype (notice type) to the API. The Actor asks for up to 1,000 notices per request, so one keyword normally costs one request.

Limits worth knowing

  • A personal, non-federal key has a small daily request allowance. Keep the keyword list short on SAM.gov schedules.
  • SAM.gov matches keywords against the notice title, and the posted-date window is at most one year.
  • Without a key the SAM.gov source is skipped with a log line; a rejected key produces a SAM_AUTH_FAILED error item.
  • Points of contact are returned exactly as the agency published them.

The same Actor also reads six state and local bid datasets from city, county and state open-data portals (Los Angeles, New York City School Construction Authority, Montgomery County, MD, Mesa, AZ, Cook County, IL and Illinois) with sources: ["sled"]. That is a small set, not a nationwide state and local feed.

How to run it

You need an Apify account and its API token (Console → Settings → API & Integrations). Each run is billed per result to your account; set a maximum total charge for the run to cap spend.

With curl

The sync endpoint starts a run, waits up to 300 seconds and returns the dataset items. Small business set-aside notices for one NAICS code in Virginia, posted in the last 7 days (replace the key placeholder with your own key):

export APIFY_TOKEN=<your Apify API token>

curl -sS -X POST \
  "https://api.apify.com/v2/acts/owlabee~grants-gov-api/run-sync-get-dataset-items" \
  -H "Authorization: Bearer ${APIFY_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
  "keywords": [
    "cybersecurity"
  ],
  "sources": [
    "samGov"
  ],
  "samApiKey": "<YOUR_SAM_GOV_API_KEY>",
  "samFilters": {
    "naics": "541512",
    "setAside": "SBA",
    "state": "VA",
    "ptype": "o,k"
  },
  "postedWithinDays": 7,
  "maxResults": 100,
  "onlyNewSinceLastRun": true
}'

FAQ

Is a SAM.gov key really free?

Yes. Any individual with a SAM.gov account can request a personal public API key from Account Details. Federal and entity-associated accounts get larger daily allowances.

What do the ptype and setAside codes mean?

They are passed straight to SAM.gov. Notice types: o Solicitation, k Combined Synopsis/Solicitation, p Presolicitation, r Sources Sought, s Special Notice, a Award Notice (comma-separate several). Set-aside codes include SBA, 8A, HZC, SDVOSBC and WOSB; the input field lists them all.

Does it read the sam.gov website?

No. Only the official API, with your key. No HTML scraping, proxies or login.

What if my daily quota runs out?

SAM.gov answers with a rate-limit error and the Actor writes one SAM_RATE_LIMITED error item for that keyword; the other sources continue.

Can it include recent awards?

Yes. includeRecentAwards adds USAspending.gov award records for the same keywords.
