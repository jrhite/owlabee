PACER RSS Feeds by Court: All 188 Federal Courts Listed

Every federal district and bankruptcy court on CM/ECF can publish a free RSS feed of its docket activity, but not all do, and many publish only some kinds of entries. This page lists all 188 courts with their CM/ECF code, whether the feed was live, and what it carries.

Where this list comes from

This table is the court registry of owlabee's PACER RSS Docket Monitor Actor, published as is. The registry was generated from a live sweep of all 94 district courts and 94 bankruptcy courts on 2026-10-17, made from a datacenter IP. It was last updated on that date. The status of each court is what that sweep saw, not a guarantee: courts change their feed settings, and a feed that was empty or did not answer may work from another network or on another day.

Each CM/ECF court's public feed lives at https://ecf.<code>.uscourts.gov/cgi-bin/rss_outside.pl and covers only the trailing 24 hours of docket activity. No PACER account is needed to read a feed; opening a linked document on PACER is subject to PACER's own fees.

At a glance

  • 135 of 188 courts had a live feed: 94 publish every docket entry type and 41 publish only some types.
  • 23 feeds answered with no entries, and 30 did not answer requests from a datacenter IP.
  • The live feeds carried 86,956 entries in their 24-hour windows at the time of the sweep.

How to read the columns

  • Live: all entry types: the feed says "Docket entries of type: all".
  • Live: some entry types: the feed publishes only the CM/ECF entry types listed, exactly as the feed advertises them (for example cmp, motion, order).
  • Answered with no entries: the endpoint exists but carried nothing during the sweep, so what it carries is unknown.
  • Did not answer: the request timed out, got an empty reply or an HTTP error from a datacenter IP, so what it carries is unknown.
  • Entries in its 24-hour feed: how many items the feed held at sweep time. It is one day's sample, not an average.

FAQ

How do I read a court's PACER RSS feed directly?

Open https://ecf.<code>.uscourts.gov/cgi-bin/rss_outside.pl with the code from the table, for example https://ecf.nysd.uscourts.gov/cgi-bin/rss_outside.pl. It is an RSS file of the last 24 hours of entries.

Do I need a PACER account?

Not to read the feeds. They are public, unauthenticated endpoints. Opening a linked document on PACER is subject to PACER's own fees.

Why do some courts publish only some entry types?

Each court chooses which CM/ECF entry types its feed includes. The table lists the types a partial feed advertises, as the feed states them.

What does "did not answer" mean?

During the sweep the court's server timed out, sent an empty reply or returned an HTTP error to a request from a datacenter IP. The feed may still work from another network.

How far back does a feed go?

Only the trailing 24 hours. To keep a running record, read the feeds at least daily; the Actor's README suggests hourly, since courts regenerate feeds every 30 to 60 minutes.

How current is this list?

It reflects the Actor's registry, generated from a sweep on 2026-10-17. Feed settings change, so a court you name is always tried and each run reports what every court returned.
