Public data sources as JSON

owlabee publishes 18 Actors on Apify Store that read public data sources (permit portals, federal APIs, court feeds, license registries, DNS, sitemaps and storefronts) and return normalized JSON. These guides explain each source, what you get from it, and how to run it with curl or from an AI agent.

Every Actor is pay per result, billed to your own Apify account; see each Store page for current pricing.

Guides

  • Building Permits API: 61 US Open-Data Portals as JSONGet building permits from 61 US city, county and state open-data portals as one JSON schema: permit type, status, dates, cost, address and contractor where published.
  • Accela Citizen Access and EnerGov Permit Data as JSONRead building permits from Accela Citizen Access and Tyler EnerGov Citizen Self Service portals in 31 US cities and counties: type, status, dates, valuation, contractor.
  • Grants.gov API: Federal Grant Opportunities as JSONSearch federal grant opportunities on the official Grants.gov API by keyword and get normalized JSON with new and updated flags, details and recent USAspending awards.
  • SAM.gov Contract Opportunities API Feed by KeywordPull federal contract notices from the SAM.gov Get Opportunities API by keyword, NAICS code, set-aside and state, with points of contact and new-notice flags.
  • OSHA Inspections by Company: DOL Data API LookupLook up OSHA inspections, violations and penalties by company name, inspection number, state or ZIP through the DOL Data API, with a name-match confidence per record.
  • EPA ECHO Enforcement Cases by Company or FacilityFind EPA and state enforcement cases in EPA ECHO by company name, FRS facility id, state or ZIP: law, status, dates, penalties and outcome, as normalized JSON. No API key.
  • Product Recalls API: FDA, NHTSA and CPSC in One FeedUS product recalls from openFDA (drugs, devices, food), NHTSA (vehicles) and CPSC (consumer products) in one normalized JSON record, with a new-recalls-only mode.
  • PACER RSS Feeds: Monitor New Federal Court FilingsRead the free public PACER RSS feeds of federal district and bankruptcy courts as JSON and filter new filings by party, case number, entry type or bankruptcy chapter.
  • Professional License Lookup: TDLR, DBPR, DORA, WA DOH, NPILook up professional licenses by name or number in Texas TDLR, Florida DBPR, Colorado DORA, Washington DOH and the NPI Registry: status, expiration, discipline flag.
  • Bulk SPF, DMARC and DKIM Checker for Domain ListsCheck SPF, DMARC, DKIM, MTA-STS and BIMI for a list of domains and get a 0-100 email security score per domain, plus RDAP WHOIS, DNS, TLS expiry and HTTP headers.
  • Sitemap Monitor: Track New, Removed and Changed PagesMonitor a website through its sitemaps: new, removed and updated pages, content changes with word-level diff previews, and a severity per change. No browser needed.
  • Shopify Price Tracker: Catalog and Changes as JSONExport any public Shopify store's catalog from products.json, every variant with price, compare-at price, availability and SKU, or track price and stock changes.

How running an Actor works

  1. Create an Apify account and copy your API token from Console → Settings → API & Integrations.
  2. Send the Actor's input as JSON to https://api.apify.com/v2/acts/owlabee~<actor>/run-sync-get-dataset-items with Authorization: Bearer <token>, or use the Python and Node.js clients.
  3. Or connect an AI agent to https://mcp.apify.com/?tools=owlabee/<actor>, Apify's hosted MCP server.

Each guide has a ready-to-run input. More examples, one folder per Actor, are on GitHub.
