How running an Actor works

  1. Create an Apify account and copy your API token from Console → Settings → API & Integrations.
  2. Send the Actor's input as JSON to https://api.apify.com/v2/acts/owlabee~<actor>/run-sync-get-dataset-items with Authorization: Bearer <token>, or use the Python and Node.js clients.
  3. Or connect an AI agent to https://mcp.apify.com/?tools=owlabee/<actor>, Apify's hosted MCP server.
  4. Or, without code, run it from Zapier, Make or n8n with Apify's official app on each platform. The no-code automation guides walk through a recipe on each.

Each guide has a ready-to-run input. More examples, one folder per Actor, are on GitHub.
